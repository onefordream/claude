# AI GOLF LAB 商品化プラン（たたき台）

スマホのカメラだけで弾道を測り、AIコーチが「今なにを練習すべきか」と「あと何ヤード伸びるか」を教えるゴルフ練習アプリ。

## コンセプト

- **起動してすぐ測れる**：ホームに「今日の診断」ボタン。5球打てば診断が出る。
- **測るだけで終わらせない**：課題 → 理由 → 今日の練習メニュー（回数つき）まで出す。
- **成長が見える**：毎回の結果が残り、キャリー・初速・打ち出し角・安定性の推移をグラフで見られる。
- **伸び代を数字で見せる**：「打ち出し角を11.5°にすると+7yd、ミートが安定すると+8yd、HSを+2m/sにすると+14yd」のように、目標値と効果を出す。

## 試作版（public/ai-golf/）でできること

| 機能 | 無料 | AIパス |
|---|---|---|
| 動画（スロー240fps）から初速・打ち出し角を計測 | ✓ | ✓ |
| 推定キャリー・最高到達点・推定ヘッドスピード | ✓ | ✓ |
| 総合スコア（パワー/打ち出し/安定性/方向性） | ✓ | ✓ |
| 記録の保存・推移グラフ | ✓ | ✓ |
| 課題の診断・今日の練習メニュー・伸び代 | 初回1回 | ✓ |
| 前回からの変化の解説 | — | ✓ |

- 計測：ボールの左端・右端をタップしてスケール（直径42.67mm）を合わせ、インパクト直後と数コマ後のボール中心をタップ。経過時間（スロー倍率で補正）と移動距離から算出。
- 弾道計算：空気抵抗＋揚力＋スピン減衰のモデル。PGAツアー平均（Dr/3W/7I/PW）のキャリーと約2%以内で一致するよう係数を調整済み。
- 診断：現在はルールベース（ゴルフ指導の定石を数値化）。`js/coach.js` の `diagnose()` が入口。

- 期間中に診断した結果は、期限が切れても見返せる（買った人の不満を出さない）。
- 有効期間中の追加購入は期限を延長。

### ストア上の扱い

- **iOS**：アプリ内のデジタル機能なので App Store の課金（IAP）が必須。期間付き買い切りは **「非更新サブスクリプション（Non-Renewing Subscription）」** がそのまま当てはまる。期限の管理はアプリ側（サーバー）で行う。
- **Android**：Google Play Billing の **消費型アイテム**として販売し、サーバーで期限を付与。
- **Web版**：Stripe などで決済。
- いずれもレシート検証と期限管理はサーバーで行い、端末の時計を書き換えても延長できないようにする。
- 特定商取引法に基づく表記、利用規約、プライバシーポリシーの用意が必要。

## 技術ロードマップ

1. **Phase 1：Web試作（済）**  
   PWAとしてホーム画面に追加できる。スロー動画を選んでタップで計測。データは端末内に保存。
2. **Phase 2：ネイティブアプリ化**（iOS 試作に着手済み：`ios/`）  
   - アプリ内で240fps撮影（Webでは高fps撮影ができないため必須）
   - ボールの自動検出（Core ML / ML Kit、背景差分＋円検出）でタップ不要に
   - 撮影ガイド（水平器、ボール位置の枠）で精度を安定させる
   - ストア課金とアカウント、クラウド同期
3. **Phase 3：AIコーチの高度化**  
   - 計測値・履歴・課題をサーバー経由でLLMに渡し、その人に合わせた解説と練習計画を生成
   - スイング動画の姿勢推定（体の回転、頭の位置）を診断に追加
   - 練習ドリルの解説動画

## 精度について（ユーザーへの説明が必要な点）

- 単眼カメラのため、測れるのは **初速と打ち出し角（上下）** まで。左右の方向とスピン量は測れない。
  - 球筋はユーザーが選ぶ方式で補っている
  - スピンはクラブごとの標準値で推定（数値入力で上書き可能）
- 精度の目安：初速 ±2〜5%、打ち出し角 ±1〜2°、キャリー ±5〜10%。
- 「レーダー式の計測器の代わり」ではなく「練習の変化を追うツール」として打ち出すのが安全。

## 見るべき指標（KPI）

- 初回診断の完了率（5球測りきれるか）
- 無料診断 → パス購入の転換率
- パス購入者の再購入率、購入間隔
- 1ユーザーあたりの診断回数／月
