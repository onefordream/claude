## 説明文

```
練習場でスマホを置いて、打つだけ。
AI GOLF LAB は、iPhone のカメラ（240fps）でボールの飛び出しを捉え、打った瞬間にボール初速・打ち出し角・推定キャリーを表示するゴルフ練習アプリです。

■ 打つだけで測れる
・三脚などでスマホを固定し、ボールの真横から構えるだけ
・ボールを自動で見つけ、打った瞬間を自動で検知
・結果は画面表示と音声でお知らせ。次のボールを置けば続けて測れます

■ 今日の診断（5球）
・総合スコア（パワー／打ち出し／安定性／方向性）
・クラブごとの目標値と比べて、今日の課題を見つけます

■ AIコーチ（AIパス）
・今いちばん直すべき課題と、その理由
・練習場ですぐできるドリルと回数
・伸び代：「打ち出し角を最適化すると+7ヤード」など、あと何ヤード伸びるかを数字で
・前回からの変化の解説

■ 成長の記録
・キャリー、初速、打ち出し角、推定ヘッドスピード、安定性の推移をグラフで
・クラブ別に記録

■ 料金
・計測、記録、グラフはずっと無料
・AIコーチは「AIパス」（1日／3日／7日）を、使いたいときだけ購入
・自動更新はありません。期間が終わっても勝手に課金されません
・初回のAI診断は無料

■ ご利用にあたって
・計測できるのは、ボール初速と上下の打ち出し角です。スピン量と左右の方向は計測しません（球筋はご自身で選択）
・キャリーとヘッドスピードは計算による推定値です
・明るい屋外ほど正確に測れます
・240fps 撮影に対応した iPhone が必要です
```

## スクリーンショット（6.9インチ・6.5インチ、各最大10枚）

並び順と、画像に入れる見出しの案です。

1. **打つだけで、すぐ数字が出る** — ライブ計測画面（初速・打ち出し角・キャリーの大きな数字）
2. **5球で、今日の課題がわかる** — 結果画面（総合スコアと4項目）
3. **あと何ヤード伸びる？** — 伸び代（+○yd と内訳）
4. **今日やる練習まで、AIが提案** — AIコーチの練習プラン
5. **成長がグラフで見える** — 記録画面の推移グラフ
6. **測定は無料。AIは使う日だけ** — AIパス画面（自動更新なし）

## App Review 向けメモ（審査担当者への説明）

```
・本アプリは iPhone の背面カメラで 240fps 撮影し、ゴルフボールの初速と打ち出し角を計測します。
  審査環境で実際に打つことは難しいため、「今日の診断」→ 測定方法「サンプル」で、計測後の画面（スコア、記録、AIコーチ）を確認できます。
・アプリ内課金「AIパス」は非更新サブスクリプション（1日／3日／7日）です。自動更新はありません。
  期限は購入日時から計算し、「購入を復元」で他の端末でも利用できます。
・AIコーチの文章は、計測した数値（初速・打ち出し角など）だけをサーバーに送り、Anthropic 社の AI モデル（Claude）で作成しています。動画や写真、個人を特定する情報は送信しません。
```
