# Growth Note（個人向け成長記録ノート）— 店舗向け開発チームへの共有資料

店舗向けアプリ（スタジオシャドウ様向けなど）を作っているチャットに、個人向けアプリの中身を伝えるための資料です。
このファイルを渡せば、個人向けアプリの全体像と、店舗とつながる部分の仕様がわかるようにしています。

- 動いているアプリ: https://growth-note-6hj5.onrender.com （お試し環境。無料プランのため、再起動で登録データが消えます）
- コード: GitHub `onefordream/claude` の `claude/personal-growth-note-design-whnhcq` ブランチ、`growth-note/` フォルダ
- 技術: Node.js 22 の標準機能だけ（外部パッケージなし）、SQLite、画面は素の JavaScript。日付はすべて日本時間

## 1. どんなアプリか

個人が毎日の取り組みを記録し、AIと振り返り、成長を数字で確かめるノートです。ジャンルは問いません（運動・音楽・ダンス・勉強など）。

| 機能 | 内容 | 料金 |
|---|---|---|
| 記録 | 文章・写真・動画・音声メモ・気分（5段階）。過去7日まで日付を選べる | 無料 |
| 継続 | 連続日数、今週の記録日数、記録カレンダー、実績 | 無料 |
| 目標 | 期限つきの数値目標（例: 20回練習する）と進捗 | 無料（同時に3つまで） |
| 検索 | 記録の全文検索（日本語対応） | 無料 |
| 教室・お店との連携 | 店舗IDを入力して連携し、記録を先生に共有・コメントをもらう | 無料 |
| AIのふりかえり | 記録ごとに要約・気づき・次の一歩 | 無料は3回まで体験、以降はプロ |
| 成長分析 | 成長レベル、6つの指標（継続力・行動量・振り返り力・目標推進力・挑戦と改善・コンディション）、推移グラフ、伸ばしたい指標 | プロ |
| AI自己分析・週間ふりかえり | 強み・傾向・来週のフォーカス | プロ |
| ゴルフ | ラウンド記録・スコアカード（無料）、能力チャート・伸びしろ・AIコーチ（プロ） | 一部プロ |

プロプラン: 月580円 / 年5,800円（税込）、初回7日間無料。Stripe で決済。

## 2. 店舗とつながる仕組み（店舗向けアプリ側で特に関係する部分）

### 流れ
1. 先生・スタッフが店舗を登録すると、**店舗ID**（例: `K7QM-4XPA`）が発行される
2. 生徒は個人向けアプリの「マイページ ＞ 教室・お店」から店舗IDを入力（招待リンク `/#/links/new?code=XXXX` でも可）
3. 店舗が承認制なら、先生が承認して連携開始（承認制はオン・オフ可能）
4. 生徒は記録ごとに「共有する店舗」を選ぶ。または「これからの記録をすべて共有」に設定
5. 先生は共有された記録を一覧で見て、コメントを書ける。生徒のホームに「先生からのコメント」として届く

### 店舗に見えるもの・見えないもの（生徒に同意画面で表示している内容）
- 見える: 生徒が共有した記録（本文・写真・動画・音声・気分）、ニックネーム、共有した記録だけから数えた継続日数
- 見えない: 共有していない記録、AIのふりかえり、目標、メールアドレス
- 連携はいつでも解除でき、解除した時点から店舗は記録を見られなくなる（記録そのものは消えない）

### 店舗側の機能（今は個人向けアプリの中の「先生・スタッフの方」画面にある）
- 店舗の登録（店舗名・ジャンル・紹介文）。1人3店舗まで
- 店舗ID・招待リンクのコピー、店舗IDの作り直し
- メンバーの承認・見送り・連携解除、メンバーごとの継続日数・共有件数
- 共有された記録の一覧（メンバーで絞り込み）、コメントの投稿・削除
- スタッフ招待コードでスタッフを追加（オーナー・スタッフの2役割）。オーナー退会時はスタッフに引き継ぎ
- 店舗プラン: お試し（メンバー30人・スタッフ3人）、スタンダード（メンバー300人・スタッフ20人）
- ジャンル: スポーツ / フィットネス / 音楽 / 語学 / 学習塾 / アート・ものづくり / ダンス / その他

### API（すべて `/api` 配下、ログイン必須、JSON）
生徒側
- `GET /stores/lookup?code=` 店舗IDから店舗を確認
- `GET /links` ・ `POST /links {code, shareMode}` ・ `GET|PATCH|DELETE /links/:id`（shareMode: `selected` / `all`）
- `PUT /entries/:id/shares {storeIds}` 記録ごとの共有先を変更
- `POST /entries {body, mood, date, mediaIds, goalId, goalDelta, storeIds}` 記録を作成（共有先も同時に指定）

店舗側
- `GET /stores` ・ `POST /stores` ・ `GET|PATCH /stores/:id`
- `POST /stores/join-staff {code}` ・ `DELETE /stores/:id/staff/:userId`
- `POST /stores/:id/regenerate-code {type: member|staff}`
- `GET /stores/:id/members` ・ `POST /stores/:id/members/:linkId/approve|reject` ・ `DELETE /stores/:id/members/:linkId`
- `GET /stores/:id/feed?member=&cursor=` 共有された記録の一覧
- `POST /stores/:id/entries/:entryId/comments {body}` ・ `DELETE /stores/:id/comments/:commentId`

権限の考え方: 店舗側の取得はすべて SQL で「その店舗に共有され、かつ連携が有効な記録」だけに絞っている。写真・動画も同じ条件で配信。

### データ（SQLite の主なテーブル）
- `stores`（店舗ID・スタッフ招待コード・承認制・プラン）
- `store_staff`（owner / staff）
- `store_links`（生徒と店舗の連携。status: pending / active、shareMode）
- `entry_shares`（どの記録をどの店舗に共有したか）
- `store_comments`（先生のコメント、既読管理）

## 3. デザインの決まり（店舗向けアプリとそろえる場合）

「紙のノートのように静かで端正」が方針。AIが作ったような見た目（丸み・グラデーション・絵文字・励まし文言）は使わない。

- 色: 背景 `#FAFAF9` / 面 `#FFFFFF` / 文字 `#111111`・補足 `#5C5C5C`・注釈 `#9A9A9A` / 罫線 `#E6E6E3`
- アクセントは深いグリーン `#1F4D3A` の1色だけ。主要ボタン・進捗・選択状態にだけ使う
- 角丸は基本2px、ボタン・入力欄4pxまで。影は使わず罫線で区切る
- 文字: IBM Plex Sans JP / IBM Plex Sans、数字は等幅（tabular-nums）。サイズは 12 / 14 / 16 / 20 / 28 / 40px のみ
- 余白は 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px のみ
- アイコンは Phosphor の形で、機能を示す場所だけ（16 / 20px）
- 文言は短く落ち着いた言葉。感嘆符は使わない（例:「記録を追加」「30日連続」）
- ダークモードあり（背景 `#0E0E0E` 系）
- 定義ファイル: `growth-note/web/css/tokens.css`（これをそのまま使えば同じ見た目になる）

## 4. 店舗向けアプリと合わせるときに決めたいこと

- 店舗向けアプリを別アプリにするか、今の「先生・スタッフの方」画面を発展させるか
- アカウントを共通にするか（今は生徒も先生も同じアカウントの仕組み）
- 店舗IDの形式・招待リンクの形式をそろえるか（今は `XXXX-XXXX`、紛らわしい文字を除いた英数字）
- 店舗向けの料金（今は店舗プランの枠だけあり、課金は未実装）
- 先生のコメント以外に、店舗から生徒へ送りたいもの（お知らせ・課題・レッスン記録など）
