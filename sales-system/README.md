# 営業支援システム（AI成長ノート × ゴルフスクール向け）

ゴルフスクールへ「AI成長ノート」を営業するための、営業メール自動送信・店舗/リサーチリスト管理・
マルチチャネル営業活動ログをまとめた社内向けツールです。

## できること

- **店舗/リサーチリスト管理**: ゴルフスクールの候補を登録し、ステージ（リサーチ中→リスト化済→
  アプローチ中→返信あり→商談中→成約/失注/NG）で進捗管理。CSVでの一括インポート/エクスポートに対応。
- **営業メールの自動送信**: メールテンプレートを作成し、選択した店舗へ一括送信。送信結果（成功/失敗、
  送信日時、本文）はすべて履歴として残ります。
- **マルチチャネルの活動ログ**: メール・DM・Instagram DM・電話・訪問など、チャネルを問わず
  営業活動を1店舗ごとのタイムラインに記録できます。
- **DM / Instagram DM の半自動運用**: テンプレートから店舗名などを差し込んだ文面を自動生成し、
  コピーして実際のInstagramアプリ等から手動で送信する運用です。
  **Instagramは自動送信ボットを規約で禁止しており、自動化するとアカウント停止のリスクがあるため、
  このシステムはInstagram/DMの送信そのものは自動化していません。** 文面作成と送信記録の管理だけを行います。

## 技術構成

- Node.js + Express（バックエンドAPI）
- SQLite（`better-sqlite3`、`data/sales.db` にファイルとして保存）
- Nodemailer（SMTP経由でのメール送信）
- フロントエンドはビルド不要のバニラ HTML/CSS/JS（`public/`）

まずはローカルPCや1台のサーバーで動かすシンプルな構成です。利用規模が大きくなった場合は、
DBをPostgresなどに、ホスティングをVPS/Renderなどに移行することを想定しています。

## セットアップ

```sh
cd sales-system
npm install
cp .env.example .env
```

`.env` を編集し、最低限以下を設定してください。

```
ADMIN_USER=admin
ADMIN_PASSWORD=（推測されにくいパスワードに変更）
```

このツールは店舗の連絡先など営業上の個人情報・機微情報を扱うため、`ADMIN_PASSWORD` 未設定時は
サーバーが起動しない仕様になっています。

起動:

```sh
npm start
```

`http://localhost:3000` にブラウザでアクセスし、`.env` で設定したユーザー名/パスワードでログインします
（Basic認証）。

## メール送信の設定

起動後、画面右上の「設定」からSMTP情報を入力してください（Gmail・SendGrid等、お使いのSMTPサーバーに対応）。

- Gmailの場合: ホスト `smtp.gmail.com` / ポート `587` / ユーザー名はGmailアドレス / パスワードは
  Googleアカウントの「アプリパスワード」（2段階認証を有効にした上で発行）
- SendGrid等の場合: 各サービスが案内するSMTPホスト・ポート・APIキーを入力

設定は保存すると即時反映され、サーバーの再起動は不要です。「テストメール送信」で動作確認できます。

## 使い方の流れ

1. **リサーチ/店舗リストを作る**: 「店舗/リサーチリスト」から1件ずつ追加、または地域リサーチで
   集めた候補をCSVでまとめてインポート。
2. **テンプレートを用意する**: 「テンプレート」でメール用・DM用の文面を作成。`{{name}}` `{{prefecture}}`
   などのプレースホルダーが店舗情報に自動差し替えされます。
3. **営業メールを送る**: 「一括送信」で対象店舗を選び、テンプレートを選んで送信。送信結果は
   店舗ごとの履歴と、送信履歴一覧の両方に残ります。
4. **DM/Instagram DMでアプローチする**: 店舗詳細画面で文面を生成し、コピーして実際のアプリから
   手動送信。送信したら「送信済みにする」を押すと活動履歴に記録されます。
5. **返信や商談の状況を記録する**: 店舗詳細画面の「活動を記録」から、返信があった・商談化した等を
   随時記録。ステージも合わせて更新していきます。
6. **ダッシュボードで全体を把握する**: 登録件数、ステージ別件数、直近7日間のチャネル別活動数、
   最近の活動を一覧で確認できます。

## CSVインポートのフォーマット

1行目をヘッダーとし、以下の列名を使用してください（`name` のみ必須）。

```
name,prefecture,city,address,phone,email,website,instagram,source,stage,owner,tags,notes
```

- `stage` は `research` / `listed` / `contacted` / `replied` / `negotiating` / `won` / `lost` / `ng`
  のいずれか（空欄や不正値は `research` になります）。
- 既存の「店舗/リサーチリスト」画面の「CSVエクスポート」で出力したファイルをテンプレートとして
  使うと確実です。

## セキュリティ・運用上の注意

- ログイン情報は `.env` の `ADMIN_USER` / `ADMIN_PASSWORD` で管理されます。`.env` は Git管理対象外
  （`.gitignore` 済み）です。
- `data/` 配下のSQLiteファイルには店舗の連絡先情報が入ります。バックアップやアクセス権の管理に
  注意してください。
- メール送信は実際に外部へメールを送信します。テスト時は自分宛のアドレスで動作確認してから、
  本番の送信先リストに対して実行してください。
- 認証はHTTP Basic認証です。インターネット経由で公開する場合は、Nginx/Caddy等のリバースプロキシで
  必ずHTTPS（TLS）を有効にしてください。HTTPのまま公開すると認証情報が平文で流れます。
